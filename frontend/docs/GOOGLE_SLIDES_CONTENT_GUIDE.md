# Google Slides Content Guide (สำหรับ CS)

> คู่มือนี้ใช้เฉพาะบทเรียนที่เลือก `contentSourceType=google_slides`; ระบบปัจจุบันรองรับ
> PDF เป็นแหล่งเนื้อหาหลักอีกทางหนึ่งด้วย

คู่มือนี้สำหรับผู้ที่เตรียมเนื้อหาสอนใน Google Slides ไม่ต้องมีความรู้ Developer

## กติกาพื้นฐาน

1. **1 Slide = 1 ช่วงการสอน** — แบ่งเนื้อหาให้แต่ละ Slide พูดจบในตัวเอง ไม่ยาวเกินไป
2. **Speaker Notes ของ Slide คือคำพูดของ AI** — เปิด View → Show speaker notes แล้ว
   พิมพ์ข้อความที่ต้องการให้ AI พูด เขียนเป็นประโยคพูดปกติ (เหมือนบทพูดจริง)
3. **ห้ามใส่คำสั่งพิเศษใน Speaker Notes** เช่น `[WAIT]`, `[CHECKPOINT]` — ระบบอ่าน Notes
   เป็นข้อความพูดตรง ๆ เท่านั้น ไม่มีการตีความ Syntax ใด ๆ
4. **วิดีโอในสไลด์ต้องปิดเสียง (Mute) เสมอ** — เสียงของ AI คือเสียงเดียวที่ควรได้ยิน
5. รูปและวิดีโอวางตาม Layout ที่ต้องการได้อิสระ ระบบแสดงตามหน้าตาสไลด์จริง ไม่ดึงออกมา
   จัด Layout ใหม่

## การตั้งชื่อและจัดลำดับ

- ตั้งชื่อไฟล์ให้สื่อความหมาย (เช่น "วิธีการ Login - Mobile App")
- เรียงลำดับ Slide ตามลำดับการสอนจริง ระบบเล่นตามลำดับ Slide ในไฟล์เสมอ ข้ามไม่ได้
- ไม่จำเป็นต้องมี Slide หน้าปก/ปิดท้ายพิเศษ — AI จะพูดทักทายและกล่าวลาเองอัตโนมัติ
  นอกเหนือจากเนื้อหาใน Slide

## การประมาณ `videoDurationMs`

ถ้า Slide ไหนมีวิดีโอ ต้องกรอกความยาว "มิลลิวินาที" ของวิดีโอนั้นในหน้า Admin
(หน้าแก้ไขบทเรียน → รายการ Slide → ช่อง "ความยาววิดีโอในสไลด์นี้")

- เปิดวิดีโอต้นฉบับ ดูความยาว (นาที:วินาที) แล้วแปลงเป็นมิลลิวินาที เช่น วิดีโอยาว
  0:08 (8 วินาที) → กรอก `8000`
- ถ้า Slide ไม่มีวิดีโอ ใส่ `0`
- ระบบจะรอ **นานกว่า** ระหว่างความยาวเสียงพูด (Speaker Notes) กับความยาววิดีโอ แล้วเว้น
  จังหวะหายใจสั้น ๆ ก่อนไป Slide ถัดไป — ถ้าตั้งค่าน้อยกว่าความยาวจริง วิดีโอจะโดนตัดก่อน
  จบ ควรกรอกให้ตรงหรือมากกว่าเล็กน้อย

## ออกแบบให้เหมาะกับ Desktop และ Mobile

- ใช้ตัวอักษรขนาดใหญ่พออ่านออกบนจอมือถือ (แนะนำหัวข้อ ≥ 28pt เนื้อหา ≥ 18pt)
- หลีกเลี่ยงข้อความ/ปุ่มเล็กเกินไปที่ต้องซูมถึงจะเห็น
- เว้นขอบ (Margin) ไม่ให้เนื้อหาชิดขอบจอเกินไป เพราะพื้นที่ Shared Screen บนมือถือแคบกว่า

## ก่อนส่งลิงก์ Session ให้คุณครู

1. บันทึก Google Slides Source URL ในหน้า Admin แล้วกด "ตรวจสอบ/Sync Slides"
2. ตรวจสอบว่า Speaker Notes แสดงครบทุก Slide ในรายการ preview (ถ้าว่างจะไม่มีเสียงพูด
   สำหรับ Slide นั้น)
3. เปิด Embed URL ที่ระบบสร้างให้ในเบราว์เซอร์ ตรวจว่าดูได้จริงและไม่มี Toolbar เกะกะ
4. ทดสอบเข้าห้องสอนเองหนึ่งรอบก่อนส่งลิงก์จริงให้คุณครู
